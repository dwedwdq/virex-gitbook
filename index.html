Permanent undetected cheat for supported games. Follow every step exactly — skipping steps causes crashes or detection.

UndetectedPermanent LicenseAdmin Required
Disable ALL antivirus software and Windows Defender before starting. Add your cheat folder to exclusions permanently.

Requirements

Setup Guide

1
Disable Secure Boot & TPM
Reboot into BIOS (usually DEL or F2 on startup). Navigate to Security → Secure Boot → Disable. Also disable TPM 2.0. Save and exit. This is required for the driver to load.
2
Disable Windows Defender & Antivirus
Go to Windows Security → Virus & threat protection → Manage settings → Turn off Real-time protection. Then add your Virex folder to exclusions so it stays off after reboot.
3
Extract & Place Files
Extract the Virex Perm ZIP to a simple path like C:\Virex\. Do not use Desktop or Downloads. Avoid paths with spaces or special characters.
Recommended path
C:\Virex\Perm\
4
Run Loader as Administrator
Right-click VirexLoader.exe → Run as administrator. Enter your license key when prompted. The loader will verify your key online.
5
Inject & Launch Game
After the loader shows READY, launch your game. Wait for the game to fully load into the main menu, then press the inject hotkey.
Default hotkey
INSERT — Open/Close menu
DELETE — Panic unload
6
Configure Settings
Use the in-game overlay menu to configure aimbot, ESP, and other features. Save your config so it loads automatically next time.
Setup complete. If you see the Virex overlay menu in-game, everything is working correctly.
